# Presse CuttleBug Remix

Le mécanisme à rouleaux d'une presse Provo Craft Cuttlebug / Cuttlekids,
récupéré sur une machine d'occasion et remonté sur une base imprimée en 3D :
un socle, deux plateaux à la même hauteur de part et d'autre des rouleaux, et
quatre rails qui tiennent le sandwich aligné pendant le passage. Sept pièces,
aucune vis entre elles — tout tient par emboîtement.
